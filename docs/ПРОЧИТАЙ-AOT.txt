Twitch Category Tracker 2.1.0 — Native AOT

Запускайте TwitchCategoryTracker.exe из распакованной папки.
Введите ник или ссылку на стримера и нажмите «Добавить».
Отдельная установка .NET не нужна. Файлы av_libglesv2.dll,
libSkiaSharp.dll и libHarfBuzzSharp.dll должны оставаться рядом с EXE.

Список каналов, настройки и история находятся в подпапке data.
При обновлении сохраните свою папку data, чтобы не потерять настройки.

Галочка в колонке «Увед.» управляет уведомлениями отдельного стримера.
При сворачивании окно убирается в трей. Двойной щелчок по значку
возле часов возвращает окно. Для завершения выберите «Выход» в его меню.

В настройках есть кнопка «Тест уведомления» для проверки уведомлений Windows.
