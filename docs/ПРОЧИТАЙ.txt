Twitch Category Tracker 2.0.1

Запустите TwitchCategoryTracker.exe, введите ник или ссылку на канал
и нажмите «Добавить».

Утилита проверяет категории каждые 30 секунд. Интервал и общие настройки
уведомлений находятся под кнопкой шестерёнки.

Галочка в колонке «Увед.» включает или выключает уведомления конкретного
стримера. Отслеживание и запись истории при этом продолжаются. Общий
выключатель уведомлений в настройках действует на все каналы.

Журнал внизу можно свернуть. Крестик у стримера удаляет канал из списка,
стрелка открывает его в браузере. Историю можно экспортировать в JSON.

Данные находятся в подпапке data рядом с EXE. Копируйте её вместе
с программой, чтобы сохранить список каналов, настройки и историю.
«Папка данных» открывает эту папку в Проводнике.

Кнопка сворачивания сразу убирает окно в трей. Двойной щелчок по значку
возле часов возвращает окно. Закрытие окна по умолчанию тоже оставляет
программу в трее. Для завершения выберите «Выход» в меню этого значка.

Программа предназначена для Windows x64 и включает среду .NET.
Используется внутренний API сайта Twitch. При его изменении может
потребоваться обновление утилиты. Частые смены категории между двумя
проверками могут быть пропущены.
